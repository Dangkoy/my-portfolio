# Demo & Experiments Directory

This folder is a **safe space** for testing new content, designs, and features without affecting the official portfolio.

## Structure

- **demo.html** - Experimental version of your portfolio (isolated from production)
- **demo-styles.css** - Custom styles for demos (keeps main styles.css clean)
- **experiments/** - Sub-folder for testing specific features or ideas

## Usage

1. Create new HTML files here to test layouts
2. Use demo-styles.css for experimental styles
3. Link back to parent ../styles.css if needed for consistency
4. Once refined, integrate changes into the official portfolio

## Important

❌ Changes here do NOT affect the main portfolio  
✅ Keep your official files safe in the root directory  
✅ Organize experiments by feature/idea in the experiments/ folder

---

**Tip:** To preview your demo, use a local server or open demo.html directly in your browser.
