🚀 Demo & Experiments

Welcome to the experimental workspace! This is where you can test new layouts, components, and features without affecting your official portfolio. Use this space to:

  • 🎨 Test new design ideas and color schemes
  • 📐 Experiment with different layouts
  • ⚡ Try new interactive features
  • 📱 Test responsive designs
  • 🔧 Refine components before adding to production

Organized sub-experiments

🧪 How to Create Experiments

1. Create a new .html file in experiments/
2. Reference ../demo-styles.css for custom styles
3. Reference ../../styles.css for base portfolio styles
4. Test and iterate freely
5. When satisfied, integrate into ../index.html
